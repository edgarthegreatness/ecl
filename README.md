# Lead Desk (demo)

Clickable demo of Lead Desk, a review-before-send inbox for Facebook Page leads.

**This is a demo only.** It uses made-up leads and is not connected to Facebook, Google Sheets, or email. Nothing is sent anywhere.

## Put it online with Netlify
1. Upload this folder to a GitHub repository (Private is recommended).
2. In Netlify: **Add new site → Import an existing project → GitHub**, and pick the repository.
3. Leave the build command empty and set the publish directory to `/`. Deploy.

You can also drag this folder onto https://app.netlify.com/drop.
